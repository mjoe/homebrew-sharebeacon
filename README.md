# homebrew-sharebeacon

Homebrew tap for [ShareBeacon](https://github.com/mjoe/sharebeacon), a macOS
menu-bar application that keeps SMB shares available and restores Finder
sidebar favorites.

## Install

```bash
brew install mjoe/sharebeacon/sharebeacon
```

## Upgrade

```bash
brew upgrade sharebeacon
```

## Maintainer

When a new ShareBeacon release is published, update `Casks/sharebeacon.rb`
with the new version and the SHA-256 of the release ZIP from
<https://github.com/mjoe/sharebeacon/releases>.
